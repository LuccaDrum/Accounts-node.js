# Accounts - A Node.js Project

Aplicação de linha de comando (CLI) para gerenciamento de contas bancárias, feita com Node.js.

## Funcionalidades

- Criar conta
- Consultar saldo
- Depositar
- Sacar
- Sair

## Tecnologias

- [Node.js](https://nodejs.org/)
- [Inquirer](https://www.npmjs.com/package/inquirer) — prompts interativos no terminal
- [Chalk](https://www.npmjs.com/package/chalk) — estilização de texto no terminal

## Como rodar

```bash
# clona o repositório
git clone https://github.com/LuccaDrum/accounts-cli.git

# entra na pasta
cd accounts-cli

# instala as dependências
npm install

# roda o projeto
node index.js
```
